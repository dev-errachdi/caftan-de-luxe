# Caftan de Luxe – قفطان الفخامة

> Maison de mode marocaine spécialisée dans les caftans, takchitas et tenues traditionnelles féminines haut de gamme.

## 🏗️ Stack Technique

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel (recommandé)

---

## 🚀 Installation

```bash
# Cloner le projet
git clone https://github.com/votre-username/caftan-de-luxe.git
cd caftan-de-luxe

# Installer les dépendances
npm install

# Copier les variables d'environnement
cp .env.example .env.local

# Modifier les variables dans .env.local
# (WhatsApp number, Instagram URL, etc.)

# Lancer le serveur de développement
npm run dev
